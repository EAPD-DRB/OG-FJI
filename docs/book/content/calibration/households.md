# Household preferences

Core preference parameters retain the OG country-model family defaults.
Most importantly, the age profile `chi_n` is borrowed unchanged from OG-USA.
It has not been calibrated to a Fiji time-use survey, and this limitation
should be considered when interpreting labor-supply responses.

Remittances are handled in the macro block. Pension contributions are
described in the tax chapter because FNPF is a funded individual-account
system and should not be conflated with central-government revenue.

`retirement_age=55` follows the FNPF retirement-entitlement age. This is a
pension-access anchor rather than evidence that every worker exits employment
at 55. Source: [FNPF full withdrawal](https://myfnpf.com.fj/full-withdrawal/).
